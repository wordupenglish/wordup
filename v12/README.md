# WordUp V12 Master Curriculum

## Philosophy

WordUp is a complete self-study English learning system.

The learner begins with the English alphabet and progresses through:

Foundation
A1
A2
B1
B2
C1
C2
Academic English

## Every Session

Every session contains:

1. Lessons
2. Practice
3. Test
4. Result
5. Progression

## Practice

Practice is designed to be:

- guided
- easier
- instructional
- feedback-oriented

## Test

The test is designed to be:

- harder
- mixed
- independent
- assessment-oriented

Passing score:

70%

## Skills

- Writing
- Grammar
- Vocabulary
- Reading
- Listening

## Writing Progression

Alphabet
→ Words
→ Sentences
→ Paragraphs
→ Essays

→ Research papers

## Grammar Progression

Sentence

→ Phrases

→ Academic grammar
