# WordUp V12.1 Real Content Engine

V12.1 adds the first real structured learning content layer.

## Levels

- Foundation
- A1
- A2
- B1
- B2
- C1
- C2
- Academic

## Content Structure

Each lesson contains:

- objective
- explanation
- rules
- examples
- common mistakes
- vocabulary
- practice
- test
- review
- estimated duration

## Engines

### Content Model

Defines the WordUp lesson structure.

### Question Engine

Supports:

- multiple choice
- grammar
- vocabulary
- writing
- reading
- context
- error correction

### Progress Engine

Stores:

- completed lessons
- completed tests
- scores
- XP
- streak
- mistakes

### Validator

Checks whether lessons contain the required educational components.

## Important

V12.1 does not replace the existing WordUp interface.

The existing V10/V11/3D interface remains untouched.

The next integration stage will connect this content engine to the 3D interface.
